gavel Regras de Negócio Críticas

Financeiro

  • Processamento via Stripe Connect.
  • Taxa de cancelamento: 20% se < 2h.
  • Retenção de impostos automatizada.

Geolocalização

  • Check-in obrigatório via GPS (radius 50m).
  • Tracking em tempo real durante o banho.
  • API Google Maps para rotas otimizadas.

Privacidade (LGPD)

  • Criptografia AES-256 para dados sensíveis.
  • Anonimização de logs após 90 dias.
  • Consentimento explícito para push notifications.

Operacional

  • Limite de 3 cães por lavador simultâneo.
  • Validação de vacinas via OCR.
  • Assinatura digital no checkout.
